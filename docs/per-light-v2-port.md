# Per-light v2 → BBS 2.6

Состояние 2026-09-16: порт принят пользователем к коммиту, собран и установлен в Prism Reff для 1.20.1. `computer-use` запрещён; визуальная проверка Reff остаётся у пользователя. Ранее dev-клиент 1.20.4 запускался по его команде, загрузка Flat на RTX 3060 подтверждена логом.

Цель: общий `master` для Minecraft 1.20.1/1.20.4, BBS 2.6 и Complementary Reimagined. Исходник: `Desktop/IRLights-PerLight-VL-Outline-v2`. Существующие surface-wave 2, кластеризация и оптимизации теней сохранены. Отдельной ветки 1.20.1 нет: целевой артефакт собирается через `-Pmc=1.20.1`; merge-коммит не требуется. Редактор, DOF и ветки 1.21.x не портировались.

## Реализация

- У Point/Spot общие `LightForm` и `LightEffects`, персональные VL/Outline и два независимых списка получателей. Основные старые ключи форм сохранены.
- Качество VL (steps/strides) и размер пикселя Outline берутся из глобальных настроек. Режимы персональных эффектов переключаются в редакторе формы; числовые параметры и списки доступны на таймлайне.
- Списки `outline_replays` и `light_replays` — обычные строковые каналы BBS со ступенчатой сменой целого JSON. Редакторы зарегистрированы через `bbs-client-addon` / `RegisterKeyframeEditorsEvent.registerProperty`; отдельный тип ключа не нужен.
- В редакторе формы и ключа используется штатный пикер Orbit/Tracker (`UIAnchorKeyframeFactory.displayActors`). Клик переключает реплей, `None` очищает список, изменения применяются сразу; меню остаётся открытым для выбора нескольких реплеев. Выбранные строки отмечены галочками. Собственный `ReplayMultiPicker` удалён.
- Редактор ключа списка показывает и позволяет менять переключатель фильтра всей формы. Для Outline там же доступны `Own outline settings` и `Outline`, виден режим наследования. Это настройки всей формы, отдельные boolean-треки не добавлены. В форме и ключе явно показан `Filter OFF: list ignored`; персональные параметры Outline заблокированы при наследовании глобальных.
- В отличие от пакета для BBS 2.3.1, ссылки используют стабильные ID реплеев BBS 2.6: `{"film":"film/id","replays":["replay-id"]}`. Старый формат списка по индексам из чужой v2-сборки автоматически не мигрирует. Это не затрагивает фильмы, сохранённые до появления профилей.
- Включённый пустой список не выбирает никого. Выключенный фильтр хранит список. По уточнению пользователя от 09-16 списки полностью независимы: `Lit Replays` ограничивает diffuse/GGX, `Outline Replays` — только обводку. Реплей может получать Outline без освещения этим источником, даже при пустом включённом `Lit Replays`. При выключенном Outline-фильтре обводка не ограничена списками. Атмосферный VL и состав кастеров теней от списков не зависят.
- Категория Light добавлена к enum BBS; треки сгруппированы через `TrackCatalog`. Голые корневые формы света исключены из списка получателей, модели с дочерними источниками доступны.
- `irl-core:1.1.7`: исходный префикс SSBO7 (16-байтный заголовок, 96-байтные источники) сохранён. Профили 112 байт начинаются с 196624, массив целей — с 426000, маркер — `0x49524C50`. Контракт патча остаётся `@irlite 1`.

## Проверка пользователем

Dev-клиент: JDK 21, `./gradlew.bat runClient '-Pmc=1.20.4' '-Pquickplay=Flat' --console=plain`. Выбранный `run/shaderpacks/ComplementaryReimagined_IRLights` и `run/irlite/patches/complementaryreimagined.irlights` уже совпадают с проверенным патчем.

1. Открыть Point/Spot, проверить собственные VL/Outline и возврат к глобальным настройкам.
2. Проверить Light-категорию и группы у корневого и дочернего источника, редакторы обоих списков: штатное меню Orbit/Tracker, добавление/снятие нескольких галочек, `None`, закрытие по Escape/клику снаружи. Поиск появляется по штатному правилу BBS при более чем 12 строках.
3. Проверить получателей освещения/бликов и Outline: пустой список, несколько реплеев, непересекающиеся списки (обводка на реплее без освещения). Отдельно проверить сложные прозрачные формы.
4. Сохранить фильм, открыть снова и воспроизвести ключи; проверить выбор после перестановки реплеев.
5. Проверить прежние свет, тени, гобо и глобальные surface-настройки.

Известное ограничение старого Intel UHD-драйвера: `readonly restrict buffer` при GLSL 130 может мешать компиляции `deferred2`. Канонический пак здесь не изменялся ради этого драйвера; план предусматривает игровой тест на дискретной GPU.
