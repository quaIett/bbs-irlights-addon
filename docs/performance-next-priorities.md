## Результат реализации

По указанию пользователя версия сохранена на **1.1.6**: core, IRLite,
обе зависимости аддона и общий tools/VERSION согласованы.
После повторной публикации core обновлён локальный Loom remap; вложенное ядро
проверено по SHA-256. Это локальная сборка для MC 1.20.4,
не общий релиз всех MC-линий. Старые deliverables сохранены.

Объём одного cluster-upload теперь зависит от числа **упакованных** источников:

| Число источников | Было, байт/кадр | Стало, байт/кадр | Сокращение |
| --- | ---: | ---: | ---: |
| 0–32 | 152 080 | 6 928 | 95,4% |
| 33–64 | 152 080 | 9 232 | 93,9% |
| 2048 | 152 080 | 152 080 | 0% |

Это сокращение трафика **конкретного SSBO**, не измерение FPS, общей VRAM или
полного времени GPU. Максимальная ёмкость GPU-буфера сохранена. Все 21
поставляемый shader variant уже читают runtime stride из header.w; legacy
uvec2[576] остаётся по прежнему смещению. Этот CPU-этап не менял шейдеры;
последующий VL-проход описан в performance-vl-2026-09-11.md.

Ошибка host-cell проверена на исходном коде: регрессия падает на переходе
0,9 → 1,1. Исправленный код проходит её по всем трём осям и на отрицательных
координатах, а также сохраняет инвалидизацию для пустых и пересекающихся секций.
